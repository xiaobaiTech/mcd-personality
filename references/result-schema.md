# 报告卡数据契约 result.json

`scripts/render.py` 的输入。由 `scripts/judge.py` 产出，交给 `render.py` 渲染 HTML。

```jsonc
{
  "persona": {
    "code": "M01",              // 人格编号，同时用于找图 assets/personas/M01_*.png
    "name": "麦满分信徒",
    "emoji": "🌅",
    "rarity": "R",              // N / R / SR / SSR，决定角标配色
    "hero_tag": "麦当劳人格测试 · 2026",   // 图右下角小标签
    "tagline": "别人被闹钟叫醒，他被板烧香醒。",  // 一句话画像
    "quote": "早八不苦，麦满分是甜的",       // 金句
    "color1": "#FF8A00",        // 卡片主色（顶部条 / 序号圆点 / 金句底）
    "color2": "#4EC3F5",        // 卡片副色（角标 / 图片底 / 小标题 / 分享区）
    "axes": ["☀ 晨型", "✨ 尝鲜党", "💰 精算流", "🧍 独狼"]   // 四维代号，空数组则不渲染
  },

  "reasons": [                   // 恰好 3 条，每条引用真实数据
    "10 单里有 5 单在早上 10:30 前下单，最早的一单落在 08:45",
    "原味板烧鸡腿麦满分点了 3 次，是全部订单里出现最多的单品",
    "豆浆出现 3 次、薯饼 2 次"
  ],

  "data": [                      // 数据面板，2 列网格；wide=true 横跨两列
    { "k": "有效订单", "v": "10", "unit": "单" },
    { "k": "最爱单品", "v": "原味板烧麦满分 ×3", "wide": true }
  ],

  "subs": [                      // 隐藏副格，最多 2 个；空数组则整块不渲染
    { "code": "M09", "name": "无糖自律党", "emoji": "🥗", "desc": "无糖养生系数 0.60" }
  ],

  "egg": {                       // 隐藏彩蛋 MX；为 null 则整个彩蛋区不渲染
    "code": "MX", "name": "过期冤种", "emoji": "⏳", "desc": "1345.2 分已经悄悄过期"
  },

  "share": {
    "big": "来 @ 一个你觉得一定是「薯条原教旨主义者」的朋友",
    "small": "让他也拉一次自己的订单，看看是不是同一种动物",
    "stamp": "测一测你的麦当劳人格 →"
  },

  "footer": "数据来自你的真实麦当劳订单，全程只读 ｜ 生成于 2026-10-09"
}
```

## 兜底规则（模板侧已实现）

| 场景 | 行为 |
|---|---|
| `egg` 为 `null` | 不渲染彩蛋区 |
| `subs` 为空数组 | 不渲染副格区 |
| `axes` 为空数组 | 不渲染四维代号行 |
| `data` 少于 6 项 | 网格自适应，不留空位 |
| 某个接口失败（如积分） | 由 judge 决定不把那几格放进 `data`，报告自动变短 |
| `code` 找不到对应图片 | 图片位留空，卡片仍可渲染（不报错） |
| `M00 见习麦友` | `axes` 传空数组、`subs` 传空数组、`egg` 传 null |

## 校验

```bash
python3 scripts/render.py result.json -o report.html   # 字段缺失不报错，按空值降级
```
